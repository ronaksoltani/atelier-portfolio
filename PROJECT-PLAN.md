# Project plan: Atelier North

## Brief

**Type:** Website design

**Problem:** Creative portfolios can bury the reasoning and craft behind polished outcomes.

**Audience:** A potential client reviewing a small identity and digital studio.

## Experience flow

1. Arrive at a direct, descriptive introduction.
2. Review the sample interface and its scope before interacting.
3. Try the core control: Filter a set of studio case studies by type.
4. See a local result or demonstration state without sending a request to a service.

## Interaction

Category controls filter case-study cards and announce how many remain.

## Key design decision

Use an editorial type system and generous case-study pacing so the work is the primary interface.

## Boundaries

Fictional studio and case studies; no client relationships are represented.

All named businesses, people, products, schedules, prices and quantitative values are fictional portfolio content. Replace them only with verified, permissioned material.

## Next iteration

Replace sample cards with consented case studies, process artifacts and accessible image descriptions.

## Learning goals

- Structure a complete page with meaningful headings, landmarks and labelled controls.
- Separate visual rules in CSS from interaction logic in JavaScript.
- Make states understandable with keyboard controls and live status text.
- Document assumptions and the boundary between a helpful prototype and a production service.
